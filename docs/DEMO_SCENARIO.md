## Что подчеркнуть (это сильные места)

1. **Клиент и сервер разделены.** Одиннадцать экранов React работают на `/api/v1/**`;
   Thymeleaf-страницы продолжают жить рядом и вызывают те же сервисы — расхождения
   между интерфейсами быть не может.
2. **Правила живут на сервере.** Маршрут записок, переходы задач, пороги риска,
   сроки хранения — всё это сервер отдаёт клиенту (`allowedActions`,
   `allowedTransitions`), а не дублирует в JavaScript.
3. **ML измерен честно.** ROC-AUC 0,617 при потолке данных 0,623 — модель упирается
   в шум, а не в алгоритм. Есть отложенная выборка, калибровка, бенчмарки.
4. **Воспроизводимость.** `python train.py` → `python eval.py` → `python analysis.py`
   дают те же числа: сид зафиксирован.
