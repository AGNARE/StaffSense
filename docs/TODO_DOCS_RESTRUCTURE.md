# Что нужно переделать в документации

Записано по просьбе владельца: структура документов собрана мной и требует
переработки. Ниже — перечень документов и что именно в них проверять.

## Документы пакета (7 файлов)

| № | Файл | Что переработать |
|---|---|---|
| 1 | `01_Пояснительная_записка.docx` | Структура разделов: сверить с требованием кафедры, переставить при необходимости. Сейчас 10 разделов + 3 приложения |
| 2 | `02_Разработка_и_план_тестирования.docx` | Разделы и приложения: уточнить, нужен ли план тестирования отдельным документом или разделом внутри другого |
| 3 | `03_Руководство_программиста.docx` | Разделы: проверить, требуется ли жёсткий состав по ГОСТ 19.505, и привести к нему |
| 4 | `04_Руководство_пользователя.docx` | Разделы: сверить с ГОСТ 19.505 (назначение, условия выполнения, выполнение программы, сообщения оператору) |
| 5 | `05_Оценка_программы.docx` | Методика расчёта: заменить мои допущения на требуемые методичкой (ставки, накладные, окупаемость) |
| 6 | `06_Практическая_работа_9_презентация.pptx` | Тема выбрана мной; заменить, если требуется своя. Состав слайдов — под требование преподавателя |
| 7 | `07_Презентация_проекта.pptx` | Состав слайдов под требование защиты |

## Что исправлять в первую очередь

1. **Состав разделов** — сейчас он мой, а не из методички.
2. **Оформление** — титульные листы, содержание, нумерация: сверить с образцом кафедры.
3. **Нумерация рисунков и таблиц** — в документах есть таблицы, но нет рисунков; если по требованиям нужны схемы, их надо добавить.
4. **Список источников** — оформление по ГОСТ 7.1, сейчас свободное.

## Как переделывать

Документы не набраны вручную: каждый собирается скриптом из `docs/deliverables/`.
Порядок правки:

```
1. Правится структура в скрипте (_gen_pz.py, _gen_testing.py, _gen_prog.py,
   _gen_user.py, _gen_estimate.py, _gen_practice9.py, _gen_defense.py)
2. Запускается скрипт — docx/pptx пересобирается
3. Проверяется повторным открытием (python-docx / python-pptx)
```

Общее оформление — в `_gost.py` (документы) и `_deck_kit.py` (презентации):
поля, шрифт, интервал, титул, нумерация страниц, фиксация таблиц. Менять
оформление нужно там, а не в каждом документе.
